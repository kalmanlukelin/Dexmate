# Dexmate Interview Practice

Practice workspace for the Dexmate Senior Software Engineer, AI Platform interview.

## Development workflow

1. Review the system specification and clarify assumptions.
2. Break the implementation into small, testable milestones.
3. Use AI assistance while reviewing and validating every change.
4. Run tests and document important design decisions.
5. Commit the final implementation and push it to GitHub.

See [INTERVIEW_CHECKLIST.md](INTERVIEW_CHECKLIST.md) for the environment readiness checklist.
